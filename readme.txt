== Description ==

AI-powered WordPress magazine theme. Pair with the Iris AI plugin for one-click summaries, per-article chat, semantic search, author voice profiles, and a conversational homepage.Every template is AI-aware — posts, authors, categories, archives, even the 404 page — so readers can ask AI about anything they are looking at. Underneath the AI layer, Vamika is still a serious magazine theme: long-form typography, an opinionated editorial colour system, responsive layouts, translation-ready markup, and optional Elementor widgets via the companion Iris Theme Kit plugin. Works fully standalone; AI features activate when the Iris AI plugin is installed.

Features:

* Magazine-style homepage with featured stories, category grids, and newsletter sections
* Immersive single-post layout with reading progress bar, Iris AI sidebar, and reaction buttons
* Full archive and category browsing with year-grouped issue grids
* Author profile pages with essay listings and stats
* Services page template for editorial consultancies
* Native integration with the IrisAI plugin for AI-powered reading companions
* Elementor widget support via the companion Iris Theme Kit plugin
* Customizer options for header CTA, footer tagline, and newsletter section
* Responsive design with mobile-first breakpoints
* Accessibility-ready with semantic HTML, ARIA attributes, and skip-to-content link

== Installation ==

1. In your WordPress admin, go to Appearance > Themes > Add New.
2. Click "Upload Theme" and select the vamika.zip file.
3. Click "Install Now" and then "Activate".
4. Optionally install the Iris Theme Kit plugin for Elementor widgets.
5. Optionally install the IrisAI plugin for AI-powered reading features.
6. Navigate to Appearance > Customize to configure theme options.

== Frequently Asked Questions ==

= Does this theme require any plugins? =

No. Vamika works as a standalone theme. The Iris Theme Kit plugin adds Elementor widget support, and the IrisAI plugin adds AI reading features, but neither is required.

= How do I set up the homepage? =

Create a page and set it as the static front page under Settings > Reading. The theme includes a front-page.php template that displays the magazine layout automatically.

= How do I customise the header and footer? =

Go to Appearance > Customize > Vamika Options to change the header CTA button, footer tagline, and newsletter section text.
